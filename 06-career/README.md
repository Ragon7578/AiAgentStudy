# 半年路线：学会做 Agent → 做出作品 → 找到工作

目标很简单：

> **半年后，你能独立完成 AI Agent 开发，并用作品找到工作。**

本仓库是前半程的「地基」；后半程靠你持续做可展示项目。

## 总览

| 阶段 | 大约时间 | 你要交出什么 |
|------|----------|--------------|
| 1. 打地基 | 第 1–4 周 | 跑通本仓库概念 + 3 个示例 |
| 2. 做作品 | 第 2–4 月 | 2～3 个可演示的 Agent 项目 |
| 3. 像工程师一样交付 | 第 4–5 月 | 测试、日志、权限、README、Demo |
| 4. 求职包装 | 第 6 月 | 作品集 + 面试故事 + 简历项目描述 |

## 第 1 月 · 打地基（用本仓库）

按顺序完成：

1. 读完 [01-concepts](../01-concepts/)，尤其 [角色优先](../01-concepts/07-role-vs-project.md)  
2. 跑通 [03-examples](../03-examples/) 三个脚本  
3. 自己改一版：多加一个工具，或换兼容 API  
4. 用 [04-roles](../04-roles/) + [05-projects](../05-projects/) 做完项目 A 和 C  

**月底自检**

- [ ] 能不看文档画出：LLM → 工具 → 循环 → 停止条件  
- [ ] 能说清：角色和项目有什么不同  
- [ ] 有一个本地可跑的小 Agent  

## 第 2–4 月 · 做能给人看的作品

至少做 **2 个**（建议 3 个），每个都要：

- 有真实问题（自己或他人会用）  
- 有角色卡（不要一项目一只要命大 Agent）  
- 有 README：怎么跑、架构图、限制是什么  
- 有短 Demo（录屏 1～3 分钟或 GIF）  

**作品选题（选自己能坚持的）**

| 方向 | 示例 | 面试官容易问什么 |
|------|------|------------------|
| 工作流 Agent | 周报助手、Issue 分类 | 如何防死循环？如何人工确认？ |
| 知识库 Agent | 团队文档问答 | 如何防幻觉？如何引用？ |
| Coding Agent 周边 | PR 摘要、测试失败解释 | 工具权限怎么控？ |
| 多角色流水线 | 调研 → 撰写 → 审查 | 角色如何交接？失败如何重试？ |

**质量底线（没有这些很难谈「开发工作」）**

- 最大步数 / 超时  
- 工具错误能回传给模型  
- 密钥不进仓库  
- 危险操作要确认或禁止  

## 第 5 月 · 补齐「能上班」的部分

每个作品补上至少 3 项：

1. **可观测**：打印或记录每一步 Action / Observation  
2. **可配置**：模型、Base URL、角色提示可配置  
3. **可测试**：至少对工具函数写几条单测  
4. **成本意识**：能说清一次任务大概多少步、多少 token  

可选加分：LangGraph 或 OpenAI Agents SDK 重写其中一个项目（证明你能迁移框架）。

## 第 6 月 · 求职包装

### 简历上一个项目怎么写（模板）

```text
AI Agent · 团队文档问答
- 按角色拆分 librarian / reviewer，支持只读检索与引用回答
- 实现工具白名单、最大步数与错误回传，降低幻觉与失控风险
- 提供一键 Demo 与架构说明；本地/兼容 API 均可运行
```

### 面试常问（先准备短答）

1. Agent 和 Chatbot 差在哪？  
2. 为什么按角色拆，不按项目拆？  
3. 工具调用失败了怎么办？  
4. 如何防止 Agent 死循环？  
5. 多 Agent 什么时候值得用，什么时候是过度设计？  

答案应能指回你自己的项目，而不是背定义。

### 作品集最少三件套

1. GitHub 仓库（清晰 README）  
2. 1～3 分钟 Demo  
3. 一页「我解决了什么问题」说明（中英均可）  

## 每周节奏（可长期保持）

| 频率 | 做什么 |
|------|--------|
| 每周 1 个小改进 | 新工具 / 更好提示 / 修一个失败案例 |
| 每两周 1 次回顾 | 哪次幻觉？哪次死循环？怎么改的？ |
| 每月 1 次展示 | 给朋友演示，或发一篇短复盘 |

## 能力对照（半年后应达到）

| 能力 | 初级（本仓库结束） | 可求职 |
|------|--------------------|--------|
| 单 Agent + 工具 | ✓ | ✓ 且有监控与限制 |
| 角色复用 | 理解 | 作品里真用了 |
| 多角色流水线 | 练过项目 C/D | 能讲清交接协议 |
| 工程化 | 脚本能跑 | 配置、日志、测试、文档齐全 |
| 表达 | 能解释概念 | 能用项目讲故事 |

## 一句话

本仓库帮你**入门和建立正确节奏**；  
找到工作靠的是：**半年里反复做出可演示、可讲清、可维护的 Agent。**

从今天开始：打开 [学习路线](../README.md)，完成第 1 月清单第一项。
