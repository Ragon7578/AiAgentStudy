# 01 · 什么是 AI Agent？

## Chatbot vs Agent

| | Chatbot | Agent |
|---|---|---|
| 输入 | 用户一句话 | 用户目标（可能多步） |
| 输出 | 一段文字 | 完成任务（可能调工具、改文件、查库） |
| 过程 | 一次生成 | **循环**：思考 → 行动 → 观察 → 再思考 |
| 能力边界 | 训练数据里的知识 | 知识 + **外部环境**（API、浏览器、代码、数据库） |

一句话：Chatbot 是「答题机」，Agent 是「会动手的助手」。

## 最小结构

```
┌─────────────────────────────────────┐
│              Agent Loop             │
│                                     │
│   ┌─────┐   ┌─────┐   ┌──────┐     │
│   │感知 │ → │规划 │ → │执行  │ ─┐  │
│   │Observe│ │Plan │ │Act   │  │  │
│   └─────┘   └─────┘   └──────┘  │  │
│       ↑                         │  │
│       └─────── 工具结果 ────────┘  │
│                                     │
│   直到：任务完成 / 需要用户确认 / 失败 │
└─────────────────────────────────────┘
```

三大件：

1. **模型（LLM）**：负责推理与决策  
2. **工具（Tools）**：搜索、算数、读文件、调 API……  
3. **循环（Loop）**：根据结果继续行动，而不是停在第一句回复  

## 生活类比

你让助理「帮我订明天去上海的机票」：

1. 查日历有没有冲突（工具）
2. 比价几个平台（工具）
3. 选一班合适的（推理）
4. 下单前问你确认（人机协作）

这就是 Agent：目标驱动、多步、可调用外部能力。

## Agent 能做什么 / 不适合做什么

**适合**

- 多步流程：调研 → 汇总 → 写报告  
- 需要外部数据：查天气、查库、读代码仓库  
- 重复性操作：批量改文件、跑测试、整理表格  

**不适合（或要谨慎）**

- 必须 100% 正确、零容错的决策（医疗诊断、资金划拨等需强审核）  
- 没有清晰目标或成功标准的模糊任务  
- 完全离线且无工具时——退化为普通 Chatbot  

## 常见形态

| 形态 | 例子 | 特点 |
|------|------|------|
| 单 Agent + 工具 | 客服机器人查订单 | 简单、可控 |
| ReAct Agent | 研究助手边搜边想 | 可解释的思考轨迹 |
| 多 Agent 协作 | 产品经理 + 工程师 + 测试 | 分工、辩论、评审 |
| Coding Agent | Cursor Agent、Claude Code | 改代码、跑命令、开 PR |
| 工作流 Agent | LangGraph 状态机 | 节点明确、可审计 |
