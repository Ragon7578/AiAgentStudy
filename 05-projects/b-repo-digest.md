# 项目 B · 仓库变更摘要

## 目标

回答「最近改了什么 / 谁改的」。

## 材料（项目上下文）

- `repo_path`: 当前 git 仓库  
- 默认看最近 3 次提交（可配置）  

## 启用角色（Cast）

| 角色 | 卡 | 本项目中的具体化 |
|------|----|------------------|
| Git 分析员 | [git-analyst](../04-roles/git-analyst.md) | 白名单：`status` / `log` / `diff`；超时 10s |

**不新建** `git_agent`。

## 编排

单角色：按需调用只读 git 工具 → 中文摘要。

## 验收

问：「最近三次提交做了什么？」得到可读摘要，且未执行任何写操作。

## 可迁移

同一 `git-analyst`，换 `repo_path` 或「汇总本周」时间窗，即为另一项目。
