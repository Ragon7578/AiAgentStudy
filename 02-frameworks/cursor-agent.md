# Cursor Agent（产品向）

## 它是什么

Cursor 里的 **Agent** 是面向软件工程的 Coding Agent：能读仓库、改文件、跑终端、结合浏览器/文档等工具，协助实现功能、修 bug、开 PR。

你正在用的「云端 Agent」也是同一类能力的远程形态：在隔离环境里改代码、提交、推 PR。

## 和「教程里的 Agent」关系

| 教程概念 | 在 Cursor 里的体现 |
|----------|-------------------|
| LLM | 对话所选模型 |
| Tools | 读文件、搜索、终端、编辑、MCP…… |
| Loop | Agent 多步自主推进直到完成或询问你 |
| Memory | 对话上下文 + 规则（Rules）+ 仓库代码 |
| 停止条件 | 任务完成、需确认、出错 |

学完本仓库概念后，你会更容易**写好任务提示**、**配好规则**、**用 MCP 扩展工具**。

## 用好 Cursor Agent 的要点

1. **目标要可验证**：「加登录页」不如「实现 email/password 登录，含校验与错误提示，并通过现有测试」  
2. **给约束**：目录约定、不能改的文件、API 风格  
3. **用 Rules**：把团队规范写成长期上下文，减少每轮重复叮嘱  
4. **小步提交**：大任务拆成可审查的 PR  
5. **危险操作**：生产密钥、强制推送等不要交给 Agent 盲目执行  

## MCP：给 Agent 接更多手

MCP（Model Context Protocol）让 Agent 连接外部系统（Issue、文档、内部 API）。  
本质仍是：**把外部能力注册成工具**，由模型决定何时调用。

## 练习

用本仓库当教材，让 Cursor Agent：

1. 解释 `03-examples/03-react-agent` 的循环逻辑  
2. 帮你加一个新工具（如 `get_time`）  
3. 把示例改成读取 `OPENAI_BASE_URL` 以对接国产兼容 API  

这既是学 Agent，也是学「如何指挥 Coding Agent」。
